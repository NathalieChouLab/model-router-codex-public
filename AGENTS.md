# Model Router — quality first

Work directly on trivial or tightly sequential tasks. Delegate only when separate evidence, implementation or independent verification materially helps.

- mr_scout: evidence and current documentation.
- mr_planner: unknown causes, architecture and high-impact plans.
- mr_builder: bounded implementation.
- mr_tester: independent regression tests.
- mr_reviewer: independent review of significant changes.

Start with at most two concurrent agents. Assign nonoverlapping writable paths and provide goals, constraints, inputs, acceptance criteria and return shape. The primary session owns integration, scope and final verification. Reassess after new evidence or failed checks; investigate causes before retrying. Do not delegate recursively. Obtain explicit approval before irreversible actions, deployment, credential changes or high-impact data operations. Never expand permissions or silently downgrade high-risk work. If delegation is unavailable, disclose that limitation and work directly within the authorized scope. Report actual checks and close completed agents.

These rules are guidance, not a deterministic router or security boundary. Model and effort settings follow Codex configuration unless explicitly overridden.
