# Changelog

Changes are tracked here using semantic-version-style headings. The initial V2 GitHub release was published under the existing `modelrouter` tag; this is not a newly created semantic-version tag.

## Unreleased

- Corrected README installation commands and CI badge to use main.
- Added project banner, security policy, compatibility matrix, benchmark protocol, roadmap and contribution templates.

## 2.0.0 — 2026-11-19

- Expanded the public edition from five to nine native agent definitions.
- Added optional four-model configuration and recommended reasoning efforts.
- Added phase-based routing guidance and independent verification.
- Added managed planner-to-architect migration.
- Fixed Windows CRLF ownership detection and added regression coverage.
- Added cross-platform CI; ten installer tests passed on each of Windows, macOS and Linux.
- Added launch README and example task prompts.

Runtime delegation and model access remain unverified.

## Initial public edition — 2026-11-19

- Five agent definitions, reversible installer, MIT license and portable default model settings.
