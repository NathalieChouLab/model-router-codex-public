# Roadmap

This is a proposed plan, not a delivery commitment.

## V2.0 — Public foundation (published)

Nine specialist definitions, optional model profile, checkpoint guidance, cross-platform installer CI and contributor documentation.

## V2.1 — Reliability and adoption

- [ ] Validate an actual read-only subagent invocation with inherited settings.
- [ ] Record exact Codex version, account access, models and supported reasoning levels.
- [ ] Verify bounded implementation and independent review on a disposable test project.
- [ ] Collect reproducible feedback and resolve compatibility issues.
- [ ] Standardize release tags and publish a verified demo.

## V2.2 — Evidence-based optimization

- [ ] Establish a reproducible baseline vs. Model Router experiment.
- [ ] Publish measured correctness, latency, token use and failure rates with limitations.
- [ ] Improve public routing guidance based on evidence.

## V3 — Possible future improvements

Consider configurable public policies and workflow presets only after the earlier validation work. These are possibilities, not promised features.
